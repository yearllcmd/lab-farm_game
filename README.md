### Лабораторная работа №3 — вариант 3

**Поисковик по «Энциклопедии фермера».**
В input.txt хранятся статьи справочника (по одной на строке, например: Тыква — растёт 12 дней, любит обильный полив.). Программа запрашивает у пользователя с клавиатуры поисковое слово (например, "полив"). Необходимо найти все строки, содержащие это слово (без учёта регистра первой буквы!), обернуть найденное слово внутри строки в квадратные скобки (например, ...[полив]...) и сохранить найденные статьи с их порядковыми номерами в output.txt.
